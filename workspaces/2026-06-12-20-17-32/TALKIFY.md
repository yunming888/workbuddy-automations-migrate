# 口语化改写指令块（TALKIFY）· 可嵌入 am/noon/pm 三档写稿环节

> 目标：让生成文案"像真人随口说的"，消除机械感与常见 AI 痕迹；原意与事实不变；适度多埋评论钩子（图文≤2、微头条≤1，不过度）；产物同格式、下游发布脚本零修改。
> 定位：humanizer 管"清残留 AI 腔"，本指令块管"补真人松弛感 + 评论钩子 + 衔接"。两者分工，都在【写稿正文后、发布脚本调用前】跑。
> 关系：逻辑连贯（LOGIC_COHERENCE.md 模板B）先跑，保证结构连通；本指令块再口语化。顺序：写正文 → LOGIC 模板B（衔接）→ TALKIFY（口语化+评论钩子）→ humanizer（清腔）→ 发布。

---

## 一、可直接粘贴的指令块（粘进三档 automation 写稿段，与 humanizer 并列）

```
【口语化改写·写稿正文后必跑（am/noon/pm 三档同构，不新增脚本变量）】
1. 输入 = 当前 {slot} 档正文全文（图文 toutiao_article_auto_{DATE}_{slot}.md / 微头条 toutiao_wt_auto_{DATE}_{slot}.md）。
2. 保留铁律（先立边界再动笔）：事实/数字/书名/作者/书名号/数据出处一律不改；图文首行仍 #标题、正文不写 #井号#；微头条仍以 #上头条 聊热点# 收尾；不改文件名、不加井号、不动 COVER/TOPIC。只改：语气、句式、衔接、评论钩子。
3. 口语化 8 条（补真人味，别只删 AI 腔）：
   ①第一人称+真事起头；把"该文/研究表明/值得注意的是"换成"我干施工的，今年报了注安，刷到这条…"。
   ②短句为主、偶尔一句长的；全篇禁连续三段排比。
   ③口语词克制（搁/甭/说白了/换句话说/这事），每 200 字 ≤3 个，别每句抖。
   ④删书面套话（综上/由此可见/不言而喻/值得一提的是）。
   ⑤拆"不是A而是B"否定并列为两句顺承。
   ⑥被动宏大结尾落地（"能力正被重新定义"→"谁干什么活正在重新分"）。
   ⑦段尾别全句号收，偶尔反问/省略（"…就是这么回事。"/"你说是不是？"）。
   ⑧抽象名词换具体动作（"提升认知"→"把这事拆开看"）。
4. 评论钩子（提升评论互动，总量控制不过度）：
   - 总数：图文 ≤2、微头条 ≤1。
   - 图文分布：段中 1 个（站队/征集，如"你见过哪个组织越往外推、自己反而越稳的？"）＋文末 1 个（开放式提问回扣主线）。
   - 每个钩子必须回扣正文主线，且是"具体二选一/站队/征集经历"，禁"大家怎么看"空问。
   - 钩子与"关注引导"自然并成一句，不喊口号、不站外导流。
5. 衔接（逻辑不断）：每段接住上一段；因果胶水词 ≥4 处（因此/但/关键在/回到）；前 150 字点读者利益；结尾回扣开头那个钩子。
6. 输出：覆盖原 {slot} 档 md 文件内容（同路径、同格式）；字数仍落在档内（图文 1000~1500、微头条 200~500）。
7. 自验收（发前 10 秒，全中才发布）：
   - 删掉分点编号，全文仍顺读？
   - 朗读一遍像不像真人随口说？不像→再口语一档。
   - 评论钩子 ≤ 上限且每个都回扣主线？
   - 事实/数字逐条对回原稿，一字未改？
   - 字数仍在档内？
```

## 二、嵌入位置（三档同构，脚本零改）

| 位置 | 说明 |
| --- | --- |
| 写稿正文之后 | 贴到 am/noon/pm 三档 automation 的"写图文/微头条"那一步、正文产出完 → 发布脚本调用之前 |
| 与 humanizer 并列 | 顺序 TALKIFY → humanizer；二者分工，不互相替代、不重排 |
| 不新增变量 | 只引用 {slot}/{DATE}/{体裁}（均为 prompt 已有上下文）；不碰 JS 脚本任何变量 |

**为什么脚本零修改**：`auto_publish.js`/`wt_publish.js` 只读 md 文件路径与正文文本，不解析内部措辞。本指令块产物仍是"同路径、同首行 #标题、正文无井号（图文）/末行话题（微头条）"的 md，脚本照发、台账照写、正文完整性（body_filled_len）照验——只是文字更口语、钩子更自然。

## 三、兼容性清单（逐项对齐现有约定）

- 格式：图文 = 四段（标题+引入+分点+收尾）；微头条 = 200~500 字单主题。均不破坏。
- 标题：三段式钩子模板不变，本指令只改正文与钩子，标题照旧。
- 字数档：图文 1000~1500 / 微头条 200~500，改写后须落回档内。
- 井号：图文不写 `#xx#`（发布页无话题组件）；微头条末行保留 `#上头条 聊热点#`。
- 变现：关注引导+评论钩子自然并一句，不站外导流、不喊口号。
- 数据：事实/数字/出处不动；本指令不新增数字。
- 幂等/广告/首发：均为发布脚本层职责，与本指令无关，照旧。

## 四、对照示例（拿已发《梁王1:2惜败夺银》做口语化改写，证明达标）

**改前（节选，偏叙述书面腔）**
> 德韦克在《终身成长》里把这种人叫固定型，把失败读成"我这个人不行"的；成长型不一样，他把"1比2"拆成"首局我赢了、次局我失误多了、决胜局关键分没扛住"。败局在他眼里是数据，不是结论。梁王赛后自己的原话就透这个意思：不断研究、不断前进，永远是课题。

**改后（口语化 + 段中埋 1 个站队钩子，事实/数字一字未动）**
> 这事德韦克《终身成长》讲过：固定型的人，输了就一句"我不行"，甩锅天赋、甩锅运气，下回再赌一把。成长型的人不这么干，他把"1比2"拆开——首局我赢了、次局我失误多了、决胜局关键分没扛住。败局在他眼里是数据，不是结论。你属哪种？我赌大部分人嘴上说成长型，手一抖又滑回固定型。梁王赛后那句"不断研究、不断前进"，其实就是把银牌读成"下一关练什么"。

**改后（文末开放式提问，回扣主线，关注引导并一句）**
> 你手上那件"没成"的事，别急着总结，先拆成三层：结果是啥、过程哪步丢的、下回先练哪个动作。我今年备考注安就靠这个，把这月最管用的一个习惯攒出来了。拆到卡你的那一步，评论区写出来，我陪你往下读，也方便关注我的人一起复盘。

**对照核对**
| 项 | 改前 | 改后 | 判定 |
| --- | --- | --- | --- |
| 事实/数字 | 1比2、局分、444→第1、134场103、36年、8月世锦赛 | 全部保留，未动 | ✓ 原意不变 |
| 评论钩子 | 2 个堆在文末 | 段中 1（站队）＋文末 1（开放式），图文≤2 | ✓ 适度、分布 |
| 口语词 | 偏叙述 | 少量"这事/不这么干/手一抖/攒出来了"，每 200 字≤3 | ✓ 不过度 |
| AI 痕迹 | "把这种人叫固定型"等书面并列 | 拆成口语顺承，删否定并列 | ✓ 去机械感 |
| 衔接 | 分点并列 | 段首接住上段、因果胶水 | ✓ 逻辑不断 |

> 注：以上为改写演示，不覆盖已发文件；实际三档写稿时，本指令块在正文产出后、发布脚本调用前自动执行并覆盖当次 md。
