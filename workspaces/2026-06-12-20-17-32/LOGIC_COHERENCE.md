# 逻辑连贯性增强提示词（配合 humanizer 使用，专治"思维跳跃"）

> 定位：humanizer 管"去 AI 味"（语感），本模板管"去跳跃"（逻辑）。两者分开跑，本模板放 humanizer 之前。
> 核心原则：全文只允许一条主推理链。每个段落 = 接住上一段留下的问题 + 结尾再留一个新问题。不允许"并列式罗列"。

## 一、病根诊断（为什么 AI 会跳）

| 症状 | 根因 | 判据 |
| --- | --- | --- |
| 段落间生硬切题 | 各段独立生成，无交接 | 下一段第一句若出现与上段无关的新关键词 = 跳了 |
| 缺因果衔接 | 因果只写"是什么"，不写"为什么" | 全文因果胶水词 < 4 处 |
| 读起来像条目 | 分点是"1. 2. 3."并列，非递进 | 删掉编号后段落仍顺 = 伪连贯 |
| 结尾突兀收束 | 总结段与上文无呼应 | 结尾没回扣开头或核心观点 |

## 二、方法：单链推理（Single-Chain）

写作顺序（先骨架后血肉，确保结构天然连通）：
1. **定主线**：全篇只有一个核心观点，每段必须回扣它。
2. **造骨架**：把每段写成"答题 + 抛题"，段尾留钩子（hand-off）。
3. **贴胶水**：段首用因果/转折/递进词接住上一段。
4. **回声主线**：结尾回扣开头那个钩子，闭环。

四个可执行技巧：
- **段尾埋钩**：段落结尾不停，加一句"所以自然会问 / 但关键在 / 回到这里"。
- **段首接题**：下一段第一句必须回应上一段的钩子，不许另起炉灶。
- **因果胶水**：显性写"因此 / 这说明 / 而真正 / 但问题在于 / 回到…"。
- **回声主线**：核心观点关键词全篇可顺读一遍读通；读不通的段落 = 离题，改写成"答上段的问题"。

## 三、提示词模板 A —— 写前出"推理链骨架"（保证结构连通）

```
先写这篇文章的"推理链骨架"，别写正文。规则：
1. 全文只有一个核心观点，一切顺这条线；
2. 每一步 = "回答上一步留下的问题 + 结尾抛一个新问题"；
3. 按此格式列出 5 步（开头 + 3 分点 + 收尾）：
   [第N步] 答：（一句话承接上一步） → 钩子：（留给下一步的问题）
4. 收尾固定：串起整条链 + 回扣开头那个钩子。
我看完骨架的衔接度，再动笔。
```

## 四、提示词模板 B —— 写后做"连贯性自检 + 修复"（发前跑）

```
重读全文，执行逻辑连贯性自检，逐段修复：
【查1 段尾】每段结尾有没有给下一段留钩子？"戛然而止"的段落，补一句过渡（因此/这说明/但关键在于/回到…）。
【查2 段首】每段开头有没有因果或转折词接住上段（因此/但/同时/所以/关键在于）？若段首凭空出现新关键词 = 切题，加一句"回声"呼应上段，或删并此段。
【查3 主线】核心观点关键词能否从头顺读到尾？任何一段脱离主线，改写为"回答上一段的问题"。
【查4 胶水数】全文"因此/这说明/关键在于/但/回到"至少 4 处；不足 4 处 = 跳跃，补。
只改衔接与因果，不动事实与数据。输出：修订稿 + 跳跃点清单（哪段改了什么词，≤3 条）。
```

## 五、因果胶水词速查表（按功能）

| 功能 | 词 | 用在哪 |
| --- | --- | --- |
| 顺承 | 因此 / 这说明 / 所以 / 而结果 | 段尾 |
| 转折 | 但 / 关键在 / 真正的问题是 / 但这里有个真相 | 段首 |
| 递进 | 同时 / 更关键的是 / 除此之外 | 段首 |
| 回扣 | 回到开头 / 说到底 / 归根到底 / 最后 | 收尾 |

## 六、改造示例（对照用）

改前（跳）：
> ……银牌是数据，不是结论。
> 很多人不知道，固定型思维……（凭空切到"思维"）

改后（连）：
> ……银牌是数据，不是结论。
> 所以自然会问：为什么有人能把一场败局拆成数据？关键在两点——固定型和成长型思维的分野。

## 七、自验收（发前 10 秒过一遍）

- [ ] 删掉所有分点编号，全文仍顺读 → 通过
- [ ] 每段"开头 5 字"能接住上段"结尾 5 字" → 通过
- [ ] 因果胶水词 ≥ 4 处 → 通过
- [ ] 结尾回扣了开头钩子 → 通过
